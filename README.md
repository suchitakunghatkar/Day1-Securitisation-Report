# 📑 Day 1 – Securitisation Report

This repository contains my **Day 1 learning report** from my Data Analytics internship. The report provides an overview of India's securitisation ecosystem, regulatory framework, credit rating methodologies, dataset requirements, and data field mapping used in portfolio analytics.
