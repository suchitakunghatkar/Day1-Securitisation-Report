# 📌 Project Overview

This project presents an executive summary of India's securitisation ecosystem.

The report explains

- Securitisation Process
- Regulatory Framework
- Credit Rating Agencies
- Dataset Overview
- Business Requirement Mapping
- Expected Power BI KPIs
- Day-1 Learning Outcome

The report was created entirely in **LaTeX** as part of a Data Analytics internship.
