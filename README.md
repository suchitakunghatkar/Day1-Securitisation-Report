# 🏛 Regulatory Framework

| Organization | Role |
|--------------|------|
| RBI | Regulates banks and NBFCs |
| SEBI | Regulates securitised securities |
| NHB | Housing finance guidelines |
| IBA | Banking standards |
| SARFAESI Act | Asset recovery framework |

# ⭐ Credit Rating Agencies

| Agency | Methodology |
|---------|-------------|
| CRISIL | Portfolio quality & cash flow analysis |
| Moody's | Expected Default Rate (EDR) |
| S&P Global | LEVELS Framework |
| India Ratings | Structured Finance Ratings |
